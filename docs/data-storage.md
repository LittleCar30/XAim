# 数据与任务工作区

XAim 将设置、历史记录和任务副本保存在用户数据目录。代码变更经审阅后应用到打开的项目；安装目录只存程序。

## 数据目录

Windows 默认使用 `%APPDATA%\com.xaim.app`。首次升级从 `%APPDATA%\com.xaim.desktop\xaim.db` 自动迁移，原目录保留。SQLite 生成一致的数据库副本，包括已提交的 WAL 数据；迁移失败时继续使用原目录。

主要文件和目录：

| 路径 | 内容 |
| --- | --- |
| `xaim.db` | 项目索引、配置、界面偏好、历史对话、补丁、文件基线和任务检查点 |
| `workspaces/task-*/files/` | 每个任务的独立项目副本，包括阶段性编辑与执行产生的文件 |
| `workspaces/task-*/workspace.json` | 程序维护的任务和原项目标识 |
| `backups/*.db` | 一致性检查通过的数据库备份 |

WebView 保留本地缓存用于快速显示；主题、设置偏好和输入历史同步到数据库，启动时以数据库为准。WebView 的运行时缓存仍由系统在应用本地数据目录下维护，不随数据目录迁移。

## 备份、恢复和迁移

设置页的「数据与存储」提供打开目录、占用空间、备份、恢复和迁移操作。

- 备份包含数据库中的配置、对话、补丁和文件变更内容，不包含完整任务工作区和项目本身。
- API Key 存在系统凭据库，数据库只保存凭据引用。跨设备恢复后需重新填写 API Key。
- 迁移选择空文件夹，下次启动时复制最新数据和任务工作区，成功后切换目录；原目录保留。
- 恢复选择 `.db` 备份和独立的空目录。程序先备份当前数据库，校验恢复数据，下次启动切换目录；不覆盖当前数据库。
- 默认位置中的 `storage.json` 记录自定义数据目录和待执行操作。
- `XAIM_HOME` 可以指定绝对数据路径。设置该环境变量时，以它为准，界面迁移和恢复不可用。

默认保留已结束任务的工作区 30 天，也可选择 7 天、90 天或永久。清理仅删除程序拥有且超过期限的已结束工作区，保留对话、补丁、文件基线、待确认和运行中的任务；不删除项目文件或备份。

## 重启与历史任务

异常退出后，未结束的执行任务标记为失败，保留工作区及已持久化的阶段性成果。不会假定任务已完成或自动继续调用模型。

待确认任务在重启后仍可审阅、应用或拒绝。已应用任务可撤销，操作只使用保存的文件基线，不需要 API Key；原项目文件被其他操作修改时，拒绝覆盖冲突。历史对话提供导出任务 JSON、打开工作区以及可用的审阅操作。

## 项目任务设置

执行参数按以下顺序覆盖：内置默认值、用户默认、项目共享 `.xaim/config.json`、个人项目设置。个人设置存放在本机数据库，不写入项目。

支持的共享配置示例：

```json
{
  "taskTimeoutSec": 1800,
  "maxTurns": 32
}
```

`taskTimeoutSec` 为任务总时限，范围 30–86400 秒。`maxTurns` 为工具循环轮数上限，范围 1–256。无效参数或拼错字段明确报错，设置只对下次任务生效。

项目配置只覆盖执行预算，不允许通过项目文件指定密钥或放宽工具权限。现有设置页中的索引、验证、修复和安全偏好仍未全部接入执行器，不应当作执行授权。
