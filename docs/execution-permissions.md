# 项目执行权限

对话输入栏的统一入口替代“运行项目检查”和“运行开发命令”两个本轮开关。

| 模式 | 行为 |
| --- | --- |
| 不执行程序 | 读取、分析、生成候选修改；必要开发操作受阻并提示切换权限，自动检查记录为无法验证 |
| 按需询问（默认） | 模型选择工具，程序根据真实参数生成提示，获批后继续当前任务 |
| 按项目授权 | 只有已保存的具体范围自动执行，新增范围仍询问 |

执行提示包含命令与参数、任务副本/原项目位置、网络需求或可能性及影响。“允许本轮”只批准这一范围，不能扩展为本轮任意命令；“按项目记住”保存相同范围并切换项目授权模式。用户可在入口查看与撤销保存的操作。授权等待期间不再请求模型；取消结束当前任务，不运行待授权操作。

范围身份包含工具类别、规范化相对目录、完整参数以及相关项目清单、锁文件和参数中直接引用的项目文件内容指纹。启动服务与一次性命令为不同范围；克隆还包含仓库地址、交付位置、递归子模块设置和 Git 网络配置。授权不覆盖所有同名程序，不接受来自模型的通配授权或项目文件中的信任声明。用户选择与范围保存在本机数据库，重启保留；待处理请求不恢复，重复、错任务和过期响应被拒绝。

这是程序的执行审批机制，不是操作系统沙箱。脚本以当前用户权限运行，仍可能访问其他文件与网络。范围指纹不是整个程序及依赖行为的证明。候选修改仍需单独审阅，克隆完整目录直接交付；停止已启动服务不要求再次批准启动权限。

Git 默认使用已有 Git 配置或代理环境变量，否则在 Windows/macOS 读取静态系统代理。用户也可选择直连或不含凭据的自定义 HTTP/HTTPS/SOCKS5 地址。配置只影响 XAim 的仓库下载进程，不改写用户全局 Git 配置；PAC 和代理认证尚不支持。

连接失败后保留实际退出码和原因，提示检查 Git 网络设置；修改后可使用“重试本次任务”发起同目标的新一轮。任务总时限仍包括等待授权的时间，超过时限或退出应用不会执行旧请求。

原生工具流程在每次实际开发操作与自动检查前校验权限。非工具模型的兼容补丁流程使用相同的权限检查器进行最终验证，不再通过候选评分器未经授权执行脚本；它仍不具备克隆、依赖安装与服务管理能力。开发评测等无桌面交互的调用方保持显式授权配置。
