## 复现新的在线实验

```bash
pnpm eval -- --config /path/to/config.json --allow-verification --output /path/to/report-dir
```

配置模板见 [config.example.json](config.example.json)，密钥可通过 `XAIM_EVAL_API_KEY` 覆盖。请在每次实验前保存源码提交及未提交差异、模型/网关信息、有效请求参数、授权开关、时限和工具链版本，使用独立输出目录。线上调用会产生费用，勿把配置或原始报告提交到公开仓库。
