# XAim 开发提示词手册（完整版）

> 按开发顺序排列，每一步可直接复制给 AI 编程助手使用  
> 使用方式：把 `[上下文]` 一起复制，保证 AI 有足够背景  
> 约定：每完成一步，必须跑验收，不通过不进下一步

---

## 使用说明

每一步提示词结构：

```text
[上下文] 项目背景（必带）
[目标] 本步要做什么
[输入] 依赖什么
[输出] 产出什么
[约束] 技术限制
[验收] 怎么算完成
```

**推荐 AI 助手**：Claude Code / Cursor / Codex / 通义灵码  
**工作流**：复制提示词 → AI 生成代码 → 跑验收 → 通过进下一步

```text
- JSON 输出字段为 camelCase
```
